          Microsoft Update Catalog와 벤더 배포본은 신규 탐색 집합, LOLDrivers는 알려진 사례를 점검하는 비교 집합입니다.

          수집원별 드라이버 분류 결과. 단위: 건.

          LOLDrivers 1,991건 전체가 취약 드라이버인 것은 아닙니다. 양성 대조군 평가에는 취약 라벨 1,684건만 사용했으며, 악성 드라이버 라벨 307건은 제외했습니다.

          알려진 취약 드라이버의 후속 분석 유지율

          취약 드라이버 표본의 후속 분석 대상 유지율

          PRIMITIVE·UNCLEARED·CONDITIONAL로 분류된 비율입니다. 일반 드라이버에 대한 탐지 정확도나 오탐률을 뜻하지 않습니다. 전체 표본에서 유지되지 않은 647건 중 631건은 명시적 제외, 16건은 UNREADABLE로 재분석 대상에 남았습니다.

          신규 탐색 집합의 가상 환경 관측

          신규 탐색 집합 1,398건의 가상 환경 관측 결과

          로드율 = 로드 성공 / 대상 수. 디바이스 생성률 = 디바이스 생성 / 로드 성공. 객체 생성만으로 비특권 호출자의 접근 권한이나 취약점 성립이 검증된 것은 아닙니다.

          OUT에서도 48건이 로드됐습니다. 제외 판정은 현재 평가 범위의 판단이지, 모든 환경에서 로드가 차단된다는 뜻이 아닙니다. UNREADABLE의 디바이스 생성 138건은 판독 실패 대상을 재분석 목록에 남겨야 할 이유를 보여줍니다.

          해석의 범위와 남은 과제

          분석과 재분류는 별도 측정입니다.

          전체 분석은 약 48분, 건당 평균 약 0.85초였습니다. 추출된 사실을 재사용한 분류 규칙 재평가는 약 0.2초였으며, 파일 재분석 시간과 직접 비교할 수 없습니다.
